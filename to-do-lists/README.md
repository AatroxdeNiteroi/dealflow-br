# to-do-lists — como esta pasta funciona

> Arquivo de instrução para o assistente (Claude). Leia ao iniciar uma
> sessão de trabalho neste projeto.

## O que é

Esta pasta guarda o **planejamento de trabalho entre sessões**. Cada
sessão pode deixar mapeado, para a próxima, o que precisa ser feito.

A pasta contém **vários arquivos — um por dia**. Cada arquivo lista as
tarefas daquela sessão (em geral, tarefas que a sessão anterior mapeou).

## Nome dos arquivos

Cada arquivo é nomeado pelo **dia**: `dia-<dia>.md` — por exemplo
`dia-22.md`, `dia-23.md`. O cabeçalho dentro do arquivo registra a data
por extenso (dia, mês, ano), para não haver dúvida entre meses.

## Como usar — ao começar uma sessão

1. Abra esta pasta e localize o arquivo do dia atual (ou o mais recente
   com tarefas pendentes).
2. Esse arquivo lista o que foi mapeado para fazer agora — execute as
   tarefas descritas.

## Como usar — ao planejar a próxima sessão

Quando o usuário pedir para mapear tarefas para depois, crie (ou
atualize) o arquivo do dia correspondente. Escreva cada tarefa de forma
**clara e autocontida** — uma sessão futura, sem o histórico desta
conversa, precisa entender e executar só com o que está no arquivo.
